# Nishant Tamilselvan

Portfolio Digital Architect at the Government of Alberta, in Edmonton. I set architecture direction
across five ministries and build the tooling that lets government ship AI-assisted work with a named
person accountable for every release.

## Open source

| Project | What it does |
| --- | --- |
| [Enterprise AI Framework](https://nishant-tamilselvan.github.io/enterprise-ai-framework/) | A vendor-neutral guide to architecting and governing AI in government and regulated organizations. Version 0.3.0 maps the EU AI Act, NIST AI RMF, ISO/IEC 42001, and FedRAMP to the article, clause, or control. |
| [AEGIS](https://nishant-tamilselvan.github.io/AEGIS/) | Agents for GitHub Copilot and Claude Code that turn an idea into validated requirements, an implementable architecture, and reviewed code. A named person approves every release. Install with `pip install aegis-sdlc`. |
| [microGPT interactive notebook](https://nishant-tamilselvan.github.io/microgpt-interactive-notebook/) | Andrej Karpathy's microGPT explained step by step and run live in the browser, with no dependencies. |
